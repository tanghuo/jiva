# Jiva · 探索自己的项目

2026-11-02 的独立交互原型，主题是当前 Jiva 代码项目。以本机源码快照为依据，远程仓库入口为 [tanghuo/jiva](https://github.com/tanghuo/jiva)。

验证的问题：围绕自己在做、也更有兴趣的项目，准备好的轻量讲解是否能帮助理解具体功能，并在愿意时顺着代码继续探索。

## 使用

在这个目录运行 `node preview.mjs`，打开 `http://127.0.0.1:4317`。纯 HTML/CSS/JavaScript，无需安装依赖。`dist/index.html` 也能直接打开，但浏览器对文件地址的存储支持可能不同。

- 三个入口：文字保存的调用链、资料篮到 Agent 上下文、图集的身份与专用页面。
- 项目地图和 14 份允许列表内的代码摘录，带文件、行号、基准提交、文件摘要与截取时修改状态。
- 短文、简化示意、设备朗读、替换类比、深入讲解、可选判断题。
- 保存一句话、保存自己的问题、导出 Markdown、重新打开后继续上一个话题与分支。
- 项目地图展示入口选择理由、代码依据，并区分实现事实与产品设想。
- 调研页包含 Open Notebook、Podcastfy、DeepTutor、SurfSense 的官方证据、许可证和采用成本。

## 真实能力与边界

这是体验原型，不含真实 LLM 或 RAG。讲解与分支是预先编写的；问题只会保存，不会产生自动回答。没有接入 Jiva 正式数据库。朗读调用 SpeechSynthesis，依赖设备提供中文语音；失败时保留文字并提示。状态写入当前浏览器 localStorage，无云同步，最多 300 条线索。浏览器无法持久化时明确提示并允许导出。

本版存储键为 `jiva-project-curiosity-v1`，与旧 fq-book 主题隔离；旧键没有被清除。静态源码摘录不自动同步本机，不能把它当作实时仓库分析器或完整架构审计。

`node scripts/capture-source.mjs` 可以重新截取明确允许的源码片段；运行位置要求本 Site 位于 Jiva 根目录的 `demos/` 下。脚本只读指定的源码文件，不读取数据目录、配置、凭据或用户媒体。重新截取后必须重新核对讲解并发布，不能只更新快照就默认所有文字仍然成立。
