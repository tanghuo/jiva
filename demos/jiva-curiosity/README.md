# Jiva · 顺着好奇心

2026-11-02 的独立交互原型，素材入口为 [hoochanlon/fq-book](https://github.com/hoochanlon/fq-book)。

验证的问题：收藏后，准备好的轻量讲解是否能让人更容易接近知识，并在愿意时继续深入。

## 使用

在这个目录运行 `node preview.mjs`，打开 `http://127.0.0.1:4317`。纯 HTML/CSS/JavaScript，无需安装依赖。`dist/index.html` 也能直接打开，但浏览器对文件地址的存储支持可能不同。

- 三个入口：DNS、代理、HTTPS。
- 短文、简化示意、设备朗读、替换类比、深入讲解、可选判断题。
- 保存一句话、保存自己的问题、导出 Markdown、重新打开后继续上一个话题与分支。
- 材料页展示筛选理由、原文、参考资料及未核验范围。
- 调研页包含 Open Notebook、Podcastfy、DeepTutor、SurfSense 的官方证据、许可证和采用成本。

## 真实能力与边界

这是体验原型，不含真实 LLM 或 RAG。讲解与分支是预先编写的；问题只会保存，不会产生自动回答。未复制原书，也未接入 Jiva 正式数据库。朗读调用 SpeechSynthesis，依赖设备提供中文语音；失败时保留文字并提示。状态写入当前浏览器 localStorage，无云同步，最多 300 条线索。浏览器无法持久化时明确提示并允许导出。

当前核验覆盖三个基础概念；具体软件推荐、配置步骤、链接可用性未逐章审计。作者原文与独立编写解释均能追溯到页面中的出处。
